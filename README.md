# ACTIF HOTEL website

Open index.html in a modern browser. No build or installation is needed.
For a local HTTP preview, run `python -m http.server 8080` in this folder and open http://localhost:8080.

Pages: Home, Rooms & suites, Dining, Services & FAQs, Discover Casablanca, Gallery, Contact, Reservations, and Privacy policy.

Features: responsive navigation, gallery category filters and keyboard-accessible image viewer, expandable FAQs, reservation date validation, live stay summary, and downloadable text requests. Guest information is processed in browser memory; it is not sent to a server or stored by the application.

Before accepting live bookings:
- Replace sample rooms, amenities and stock images with verified hotel content.
- Add official phone and email details.
- Connect a secure reservation backend or booking service for delivery, live availability, pricing and confirmation.
- Review and update the privacy notice for the actual hosting and booking system.

Fonts load from Google Fonts and photos from Unsplash; an internet connection is needed for these assets. The HTML, CSS, JavaScript and form processing are local. Stock photos do not depict the actual hotel.

Validation completed: JavaScript syntax, nine page shells, asset references and internal HTML links. Browser-based visual testing was not available in this environment.
